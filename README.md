# Clínica Dental Doctora Mariscal Fernández

Sitio estático de vista previa (migración desde WordPress). Página única en `index.html`, sin build ni dependencias.

Ver en local: abre `index.html` en el navegador, o `python3 -m http.server` desde esta carpeta.

Nota: el formulario de contacto usa el atributo `data-netlify="true"`, pensado para desplegarse en Netlify (hosting final del proyecto). En GitHub Pages ese formulario no envía nada — esto es solo una vista previa visual.
